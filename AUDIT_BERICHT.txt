Aufteilung der index.html ohne Build-Schritt: klassische <script src>-Dateien in fester Reihenfolge, zum Beispiel kern.js (Zustand,
  Store, dispatch), dialog-kern.js (Erkennung), aktionen.js, ansichten.js, karte-ui.js, zugang.js. Funktioniert unter file://, weil alle
  Funktionen global bleiben. Risiko: Reihenfolge von Konstanten auf oberster Ebene. Aufwand M, rein mechanisch, mit vollem Testlauf
  absicherbar. Empfehlung: vor dem Missionsgerüst, nicht währenddessen.
Eigene Missionen: Das Format missionen[] in szenario.js trägt (Ziele, Zeitfenster, Skript, Standorte, Anreise sind je Mission
  definiert). Hindernisse: isValidState verlangt jedes Szenario-Dossier im Spielstand (index.html:1094), neue Missionen brauchen also
  einen Migrationsschritt; M1-Sonderfälle stehen im Code (zum Beispiel Fensterkennungen W-01 bis W-04 in der Zeitabfrage). Vorschlag:
  je Mission eine eigene Datei mission_<id>.js mit { personen, organisationen, orte (mit Koordinaten), ketten: [{von, nach, art}],
  zeitfenster, ziele, skript mit Platzhaltern }, dazu eine Prüfroutine beim Laden. 20 bis 30 Standorte sind für Karte und Speicher
  unkritisch.
Pins mit Lageblatt: im Profil ablegen (PROFIL.pins), nicht im Spielstand, damit sie ein Zurücksetzen überleben wie eigene Dossiers.
  Migration entfällt (neues Feld mit Vorgabe []). Export als Text aus dem Lageblatt; der Export enthält dann Ihre Notizen und
  Koordinaten, sonst nichts. Größe unkritisch, solange keine Bilder angehängt werden.
MapLibre mit PMTiles unter file://: Der Abruf von Dateiausschnitten per HTTP funktioniert ohne Server nicht. Zwei Wege:
  (1) lokaler Mini-Server im Startskript. Achtung: Pythons eingebauter http.server kann keine Teilabrufe [aus Kenntnis, hier nicht
  nachgestellt]; nötig ist ein Server mit Range-Unterstützung. (2) Datei über die Dateiauswahl des Browsers öffnen; die
  PMTiles-Bibliothek kann aus einem Dateiobjekt lesen [aus Kenntnis, nicht nachgestellt]. Die Startskripte enthalten derzeit keinen
  Server. Empfehlung: Prototyp in eigener Datei mit Weg (2) beginnen.
